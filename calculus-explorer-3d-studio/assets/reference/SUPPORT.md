# Support

## I need help using the studio

- Start at the live app: <https://somphol.github.io/calculus-explorer-3d/>
- Read the [FAQ](docs/FAQ.md).
- The in-app “?” opens keyboard shortcuts; the settings dialog has export, import, and reset.

## I found a bug

Open an issue at <https://github.com/somphol/calculus-explorer-3d/issues> with:

- what you did, what you expected, and what happened;
- the unit and control values;
- browser and OS;
- a screenshot if the issue is visual;
- the console error text, if any.
