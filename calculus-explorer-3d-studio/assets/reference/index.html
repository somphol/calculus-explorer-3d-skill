ABOUT THIS RELEASE

Calculus Explorer 3D v1.0.0 is a static, offline-capable AP Calculus AB studio. It has no backend, no account system, no analytics, and no third-party fonts.

Curriculum structure mirrors Khan Academy’s AP Calculus AB units. Three.js r169 is pinned by import map. Mastery stays in your browser.

Built with OpenCode and the DeepSeek V4.1 Flash model. Source, tests, and reproduction notes are in the repository.
